# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

    * リモートリポジトリはgithub等を用いて作成する、それぞれの作業者が変更を反映させる先となるもの 
    * ローカルリポジトリは主にリモートリポジトリから作成するそれぞれの作業者が作業を行い場となるもの 

## プッシュとマージの違いは何でしょうか？

    * プッシュは現在いるブランチの内容を対象としたブランチに反映させ、マージは対象としたブランチの内容を現在いるブランチに反映させる 

## コミットとプッシュの違い

    * コミットはブランチ内での作業結果を反映するもので、プッシュはブランチの内容を別のブランチに反映するものである

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

    * 変更の内容を簡潔かつ分かりやすく書くことでのちに見返したり、他人がみたりといったタイミングで作業内容が分かりやすくなるようにするべきである。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

    * プルリクエストでマージするフローでは、作業結果をリモートリポジトリに反映させたのちにマージするため、作業者以外によるコードのレビューが可能となる。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

    * コンフリクトを起こした箇所に反映予定であった内容が複数個表示されるため、その箇所の作業者たちと連絡を取るなどして本来の目的に合致する落としどころを見つけ、その内容を作成する。
